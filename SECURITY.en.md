# Security

## Reporting vulnerabilities

If you find a possible security vulnerability, avoid posting the details in a
public issue.

Use the private contact mechanism available in the repository to report the
problem to the maintainers.

## Recommended information

When possible, include:

- Description of the problem.
- Steps to reproduce it.
- Potential impact.
- Affected version.
- Any additional information that may help investigate the problem.

Thank you for helping keep this project secure.

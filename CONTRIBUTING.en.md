# Contributing

Thank you for your interest in contributing to this project.

## Development

See `README.md` for information on how to set up the development environment.

## Changes

Before making major changes, open an issue to describe the proposal and facilitate
its discussion.

## Pull Requests

Contributions must include the corresponding tests when applicable.

Changes must maintain the quality and conventions established for the project.
